# История изменений

## 1.1.0

- Адаптивная панель кнопок действий (FlowLayoutPanel): кнопки динамически выстраиваются в один ряд на широких/развернутых экранах или аккуратно переносятся на второй ряд с выравниванием по левому краю.
- Единый гармоничный размер кнопок: ширина рассчитывается автоматически по самой длинной надписи с отступами 20 px слева и справа, высота увеличена до 35 px для комфортного отображения текста.
- «Сохранить список» теперь сохраняет только отмеченных (выделенных галочкой) пользователей, исключая невыбранные строки.
- Расширен предустановленный выбор папок в диалоге TargetFolders: добавлены популярные папки профиля (Outlook, Crypto Pro, Google Chrome, Яндекс.Браузер), сохраняя 3 стандартные папки (Desktop, Documents, Downloads) отмеченными по умолчанию.
- Детализировано логирование этапов: разделены шаги синхронизации 1С и рекурсивной изоляции прав ACL, исключая ложное ощущение зависания.

## 1.0.5

- Оптимизирован интерфейс: удалены избыточный шаг «Изоляция прав ACL» (права настраиваются автоматически при миграции и докачке) и отдельный шаг «Безопасность C:\Users».
- Возможность ручной перенастройки прав сохранена и вынесена в контекстное меню таблицы пользователей (ПКМ → «Изолировать права ACL (для отмеченных)»).
- Панель основных действий перестроена в симметричную сетку 3x2 из 5 понятных последовательных шагов и кнопки остановки.

## 1.0.4

- Устранена ошибка первого запуска (`CommandNotFoundException`), возникавшая из-за состояния гонки при очистке временного файла в хост-оболочке `ProgramGUIProtected.cs`.
- Добавлена встроенная проверка наличия модуля Active Directory (RSAT) и интерактивная автоматическая установка компонента `RSAT-AD-PowerShell` на Windows Server (или через Windows Capability на клиентских ОС).

## 1.0.3

- На шаге 2, если на целевом сервере отсутствует PST или OST, указанный в профиле Outlook, программа пропускает импорт почтовых настроек и выставляет статус «Внимание». Для IMAP этот же статус появляется, если в папке пользователя `AppData\Local\Microsoft\Outlook` нет файлов PST или OST.
- Причина пропуска видна в журнале. В итогах миграции пользователи с предупреждением подсчитываются отдельно от ошибок.

## 1.0.2

- Изменён запуск главного окна для восстановления с панели задач. Диалоги, которые блокируют главное окно, больше нельзя свернуть отдельно.

## 1.0.1

- Во время операции над доступными кнопками «Остановить процесс», «Развернуть журнал», «Справка» и «О программе» отображается обычная стрелка.

## 1.0.0

- Начало нумерации с версии 1. В сборку входят аудит Active Directory, перенос выбранных папок, докачка, проверка профилей и настройка прав.
- В шаге 6 можно отметить ярлыки, проверить предложенные цели, назначить замену или удаление и применить выбранные действия.
