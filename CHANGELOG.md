# История изменений

## 1.2.1

- Усилена изоляция прав ACL (`Apply-SingleACL`): гарантированы рекурсивные полные права (`FullControl`) для `SYSTEM`, пользователя и администраторов на весь системный каталог `AppData` (включая `AppData\Local` и вложенные каталоги), а также на все файлы реестра `ntuser*` (включая файлы транзакционных логов). Это полностью предотвращает сбой службы групповой политики при первом входе пользователя (*«Службе "Клиент групповой политики" не удалось войти в систему. Access is denied»*).
- Интеллектуальное авто-исправление в Шаге 4 («Валидация профилей»): при обнаружении несоответствий в правах ACL программа теперь предлагает в один клик автоматически переприменить и исправить права для проблемных пользователей.
- Расширено контекстное меню таблицы (ПКМ): добавлен пункт «Открыть папку профиля в Проводнике» для быстрого перехода к файлам пользователя на целевом сервере.
- Повышена видимость контекстных функций: в нижнюю информационную панель подсказок добавлено постоянное напоминание о возможностях вызова меню по клику правой кнопкой мыши (ПКМ).
- Обновлен и синхронизирован встроенный Справочный центр («Справка / Помощь (?)»): актуализированы описания всех 5 основных шагов миграции, функций контекстного меню (ПКМ), углубленной валидации ACL с автоматическим исправлением в 1 клик и счетчика объема данных с проверкой свободного места.

## 1.2.0

- Оценка объема данных (кнопка «Оценка объема»): быстрый замер объема и количества файлов выбранных пользователей по сети без копирования (Robocopy в режиме dry-run `/L /MT:16`).
- Интеллектуальный контроль свободного места: автоматическая проверка доступного пространства на целевом диске и своевременное предупреждение перед миграцией при риске переполнения (`Disk Full`).
- Умный пропуск уже перенесенных профилей: при выборе всех пользователей кнопкой «Выбрать все» программа автоматически определяет готовые профили и предлагает пропустить их, экономя время и исключая повторную перезапись.
- Статус готовности профилей: при повторном запуске программы, аудите OU и перезагрузке списка отображается актуальный статус готовности уже перенесенных профилей.
- Новая колонка «Размер» в таблице пользователей с численной сортировкой по клику на заголовок (от самых тяжелых профилей к легким).
- Интерактивная детализация: двойной клик на ячейке размера открывает окно с разбивкой объема по каждой конкретной папке (`Desktop`, `Documents`, `Outlook`, `1C` и др.).
- Динамический счетчик: вынесен в отдельную строку между служебными кнопками и шагами миграции для исключения наложения элементов; отображает суммарный объем отмеченных пользователей в строке состояния (`Всего: X | Выбрано: Y | Объем: Z ГБ`).
- Безопасное сохранение и загрузка: колонка размера и цветовые статусы готовности поддерживаются в `AuditList.json` с обратной совместимостью с предыдущими версиями.
- Гармонизация интерфейса: строгие нейтральные серые кнопки служебных действий («Выбрать все», «Снять выбор», «Сохранить список», «Загрузить список») и отступы 10px вокруг кнопки «Развернуть журнал».

## 1.1.0

- Адаптивная панель кнопок действий (FlowLayoutPanel): кнопки динамически выстраиваются в один ряд на широких/развернутых экранах или аккуратно переносятся на второй ряд с выравниванием по левому краю.
- Единый гармоничный размер кнопок: ширина рассчитывается автоматически по самой длинной надписи с отступами 20 px слева и справа, высота увеличена до 35 px для комфортного отображения текста.
- «Сохранить список» теперь сохраняет только отмеченных (выделенных галочкой) пользователей, исключая невыбранные строки.
- Расширен предустановленный выбор папок в диалоге TargetFolders: добавлены популярные папки профиля (Outlook, Crypto Pro, Google Chrome, Яндекс.Браузер), сохраняя 3 стандартные папки (Desktop, Documents, Downloads) отмеченными по умолчанию.
- Детализировано логирование этапов: разделены шаги синхронизации 1С и рекурсивной изоляции прав ACL, исключая ложное ощущение зависания.

## 1.0.5

- Оптимизирован интерфейс: удалены избыточный шаг «Изоляция прав ACL» (права настраиваются автоматически при миграции и докачке) и отдельный шаг «Безопасность C:\Users».
- Возможность ручной перенастройки прав сохранена и вынесена в контекстное меню таблицы пользователей (ПКМ → «Изолировать права ACL (для отмеченных)»).
- Панель основных действий перестроена в симметричную сетку 3x2 из 5 понятных последовательных шагов и кнопки остановки.

## 1.0.4

- Устранена ошибка первого запуска (`CommandNotFoundException`), возникавшая из-за состояния гонки при очистке временного файла в хост-оболочке `ProgramGUIProtected.cs`.
- Добавлена встроенная проверка наличия модуля Active Directory (RSAT) и интерактивная автоматическая установка компонента `RSAT-AD-PowerShell` на Windows Server (или через Windows Capability на клиентских ОС).

## 1.0.3

- На шаге 2, если на целевом сервере отсутствует PST или OST, указанный в профиле Outlook, программа пропускает импорт почтовых настроек и выставляет статус «Внимание». Для IMAP этот же статус появляется, если в папке пользователя `AppData\Local\Microsoft\Outlook` нет файлов PST или OST.
- Причина пропуска видна в журнале. В итогах миграции пользователи с предупреждением подсчитываются отдельно от ошибок.

## 1.0.2

- Изменён запуск главного окна для восстановления с панели задач. Диалоги, которые блокируют главное окно, больше нельзя свернуть отдельно.

## 1.0.1

- Во время операции над доступными кнопками «Остановить процесс», «Развернуть журнал», «Справка» и «О программе» отображается обычная стрелка.

## 1.0.0

- Начало нумерации с версии 1. В сборку входят аудит Active Directory, перенос выбранных папок, докачка, проверка профилей и настройка прав.
- В шаге 6 можно отметить ярлыки, проверить предложенные цели, назначить замену или удаление и применить выбранные действия.
