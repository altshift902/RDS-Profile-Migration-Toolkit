# RDS Profile Migration Toolkit

Графическая утилита для администратора RDS. Работает на целевом сервере Windows и переносит выбранные папки профилей пользователей одного домена с исходного сервера по SMB.

[Скачать готовый EXE](https://github.com/altshift902/RDS-Profile-Migration-Toolkit/raw/refs/heads/main/GUI/ProfileMigrator_GUI.exe)

## Сборка и запуск

На Windows с Windows PowerShell 5.1 и компилятором .NET Framework 4.x выполните в корне репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скопируйте `dist\ProfileMigrator_GUI.exe` на целевой сервер и запустите его с правами администратора. Нужны модуль ActiveDirectory (RSAT), доступ к контроллерам домена и разрешения на чтение исходных профилей через административный ресурс C$. При первом запуске приложение создаёт рядом с EXE файл `pm_config.json`.

## Порядок работы

1. Укажите исходный сервер, OU и папки переноса, затем сохраните параметры. По умолчанию выбраны Desktop, Documents и Downloads.
2. Выполните аудит OU и отметьте пользователей. Список с галочками можно сохранить и загрузить при следующем запуске.
3. Завершите сеансы мигрируемых пользователей и запустите шаг 2. Утилита находит профиль по доменному SID, при необходимости регистрирует существующую папку или создаёт профиль, копирует данные и применяет права. Дополнительная опция переносит настройки классического Outlook POP3/IMAP. Этот режим экспериментальный. Проверьте получение почты и привязку PST под тестовой учётной записью.
4. При необходимости запустите докачку, настройку прав и проверку профилей. Шаг 6 показывает изменения ярлыков и запрашивает подтверждение. Шаг 7 меняет права общего каталога профилей независимо от выбора пользователей.

Перед массовой миграцией проверьте вход на RDS и работу приложений на одном профиле. Подробности каждого шага доступны в справке программы.
